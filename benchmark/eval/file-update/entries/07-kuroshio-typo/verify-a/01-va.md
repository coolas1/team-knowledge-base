# VA-07.01 — Correct track name

## Answer

**Kuroshio** (Track 3 on the Tidal EP).

## Sources

- `music/field-recordings-okinawa.md` — Recording 2 section: "Used in: Track 3, 'Kuroshio'".
- `music/tracklist.csv` — track 3 entry with correct spelling.

## Reasoning

The track is named "Kuroshio" (after the Kuroshio Current that flows past Okinawa). A typo in field-recordings-okinawa.md spelled it as "Kuroshiro" in a few places. After the fix, all occurrences read "Kuroshio".

## Gotchas

None. The correct spelling is unambiguous from tracklist.csv.
