# Acceptance Criteria — Reading cross-references

## Minimum findings (must be present)

The generated `notes/reading-cross-refs.md` must:

1. **Identify at least 3 books** that appear in 2+ project areas.
2. **Link to source files** for each book (e.g., `raw/notes/reading-list.md`, `raw/ideas.md`, `raw/fermentation/recipes.md`).
3. **Describe how each book connects** to each project area it appears in.
4. **Include Schafer (1977) *The Soundscape*** — must be present as a cross-reference between music and ideas.
5. **Include Katz (2012) *The Art of Fermentation*** — must be present as a cross-reference between fermentation and ideas.
6. **Include Strogatz (2003) *Sync*** — must be present as a cross-reference between music and ideas.

## Expected structure

The file should have:
- A header/title
- For each cross-referenced book: book title, author, year, list of project areas, explanation of how it connects to each area
- Source file references (relative paths from `raw/`)

## Scoring notes

- Extra cross-references beyond the minimum 3 should be recognized for bonus knowledge credit.
- Missing any of the 3 required books deducts proportionally.
- Purely listing books without explanations or source links loses quality points.
