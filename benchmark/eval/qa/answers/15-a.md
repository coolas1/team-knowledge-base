# A15 — RYK-03 peak bleaching quarter

## Answer

**2023 Q3** at **92.4%** bleaching.

## Sources

- `raw/research/bleaching-survey-2024.xlsx` → sheet `Bleaching_quarterly_pct`,
  column `RYK-03`, row `2023Q3` → value `92.4`.

## Reasoning

Full RYK-03 column (20 quarters):

```
2020Q1 27.6   2021Q3 39.3   2023Q1 48.2
2020Q2 39.0   2021Q4 26.8   2023Q2 81.9
2020Q3 29.7   2022Q1 34.7   2023Q3 92.4  ← max
2020Q4 21.5   2022Q2 51.4   2023Q4 52.5
2021Q1 17.6   2022Q3 39.4   2024Q1 41.2
2021Q2 40.9   2022Q4 31.7   2024Q2 48.4
                             2024Q3 45.1
                             2024Q4 37.2
```

Max is 92.4 in 2023Q3, the peak of the Pacific marine heatwave.

## Gotchas

- The RYK-03 column is in the **middle** of the wide sheet (12 site
  columns). Don't accidentally read RYK-02 or RYK-04.
- Bleaching percentages are stored as raw numbers (e.g., `92.4`), not as
  `0.924`. The column header is `Bleaching_quarterly_pct`, so the values
  are already in percent units.
