## Reasoning

PDF text extraction is required (the markdown mirror carries only the
abstract's rounded value, not the precise CI). §3.2 in the PDF gives
both the precise point estimate (8.36) and the 95% CI bounds (7.91,
8.82). The abstract's "≈ 8.4" is a deliberate rounding for readability.

## Gotchas

- The markdown mirror (`coral-resilience-paper.md`) only mentions the
  abstract's rounded value (8.4). For the precise CI, the PDF is the
  canonical source. A retrieval agent that only reads the markdown will
  miss the (7.91, 8.82) bounds.
- The breakpoint is "statistically indistinguishable from the NOAA Alert
  Level 2 threshold" per the discussion — i.e., the NOAA threshold is
  DHW ≥ 8, which is inside the CI.
