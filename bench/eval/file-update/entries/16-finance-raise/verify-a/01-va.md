# Verify-A 01 — July savings after raise

## Answer

1709 USD

## Sources

- `raw/notes/finance-2024.csv` — Jul row after edit: `Jul,5200,2200,525,233,191,130,0,212,1709`

## Reasoning

The raise increased July income from 4857 to 5200 USD. With all expenses unchanged (rent=2200, food=525, research=233, music=191, fermentation=130, travel=0, other=212), savings = 5200 - 2200 - 525 - 233 - 191 - 130 - 0 - 212 = 1709.

## Gotchas

A naive agent might update the income column but forget to recalculate savings. The savings value must be 1709, not the original 1366.
