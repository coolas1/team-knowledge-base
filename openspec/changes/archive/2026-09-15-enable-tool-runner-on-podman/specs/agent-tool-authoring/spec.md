## ADDED Requirements

### Requirement: 运行环境兼容性

执行网关 SHALL 通过 Docker 兼容容器 API 管理任务容器，并且仅使用 Docker
与 rootless podman 的兼容端点都接受的创建与清理选项。任务临时可写目录的
挂载选项 SHALL 不依赖单一运行环境特有的参数。任务结束、失败、取消以及
网关启动时的历史任务清理 SHALL 先强制终止（SIGKILL）再删除任务容器，
使卡死任务（死循环、进程洪泛）的清理在两种运行环境下都在网关请求时限
内完成，不依赖运行环境各自的默认停止超时。

#### Scenario: 在 rootless podman 上执行

- **WHEN** 部署将网关连接到 podman 的 Docker 兼容套接字并提交任务
- **THEN** 任务在一次性容器中真实执行并返回结果，网关健康检查报告运行环境可用

#### Scenario: 卡死任务的及时清理

- **WHEN** 任务超过时限且程序不退出（如死循环或大量派生进程）
- **THEN** 网关在自身请求时限内强制终止并删除该任务容器，后续任务不被阻塞

#### Scenario: 网关重启清理历史任务

- **WHEN** 网关重启时存在上次运行遗留的任务容器
- **THEN** 网关只清理自身拥有的任务容器，且清理卡死容器时同样先强制终止再删除
